# Intrudução a ferramenta Access

## Acces

O Access é uma ferramenta utilizada na criação de bancos de dados e tabelas. o Access é um software muito utilizado para gerenciar e criar banco de dados relacionais, através de sua interface gráfica possuimos a possibilidade de criar e gerenciar banco de dados relacionais, além disso o Acces possui uma gama de ferramentas que possibilitam de criação de estruturas até a compatibilização com linguagens e ferramentas externas.

## Interface

A interface do Acces segue uma lógica bem simples. A interfaface tanto no processo de criação inicial quanto no processo de construção abordam sistemas bem simples, possuem muitas opções porém é facil de compreender a grande parte das ferramentas oferecidas pelo software.

- Processo de criação: O processo de criação de bancos de dados, inicialmente se apresenta podendo exportar um banco de dados existente ou criar um do zero, o processo de criação podemos escolher nome e o caminho do arquivo onde o banco será armazenado. Ao final do processo de criação começamos com uma tabela vazia "Tabela1"

- Processo de construção: No processo de construção do banco podemos editar a tabela base "Tabela1" ou criar outra tabela. O ponto mais importante no processo de construção é a opção de `Modo de Exibição` que possibilita a criação da `Modo de Exibição de Folha de dados` que é básicamente a junção das colunas criadas a partir da opção `Modo Design` que compõem a tabela. 

    - Modo de Exibição: O modo de exibição é uma opção dentre as opções expostas pelo Access que muda o modo de percepção, alternando entre a criação de colunas e a junção dessas colunas, sendo a criação responsavel por criar as colunas e suas regras e a tabela sendo a junção e execução dessas regras.

        - Modo de Exibição de Folha de dados: O modo folha de dados é a junção das tabelas, é aqui que os dados são colocados, sendo eles os dados respectivos de cada coluna (ex: João fica na coluna nomes).

        - Modo Design: O modo design é a criação das colunas, aqui é onde colocamos as exigencias de cada coluna (Tipo de dado, Descrição, Nome, etc...).

Resumindo de forma simples, o Access trabalha com os modos de exibição para construção do banco, sendo o Design o que cria as regras e a folha de dados quem executa as regras.

## Relações

Dentro do Access construimos relações de forma bem simples. A construção de relações no Access parte da ligação de tabelas, onde ligamos as tabelas apartir da aba `Ferramentas de Banco de Dados` na opção `Relações`, dentro das relações as ligações abordam uma mecânica bem simples, basta arrastar as tabelas desejadas e caso a uma ligação basta segura o botão direito do mouse em cima da coluna que irá ser relacionada, arrastando a linha criada por essa interação até a outra coluna que será relacionada.

## Resumo

O Access inicialmente mostra-se como um software simples. Apesar de simples inicialmente, o Acces é um software bem robusto que nós apresenta muitas possibilidades, no conceito inicial não exploramos quase nada das ferramentas dísponiveis para o uso.
