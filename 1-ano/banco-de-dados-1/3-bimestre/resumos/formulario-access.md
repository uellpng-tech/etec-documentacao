# Microsoft Access criação de formulários

## Formulários

Um formulário dentro do Access é nada mais nada menos que uma interface para os dados de um banco de dados. Os formulários no Access são interfaces gráficas que permitem interações simples para edição de dados em um banco de dados (inserir, editar, visualizar...), ele pega os dados de um banco de dados e mostra esses dados em um formulário, isso possibilita o fácil entendimento e a simplisidade de editar esses dados atráves de botões, caixas de texto e menus, tirando a interação com as linhas e colunas, que são complicadas para alguns usuários. 

## Como criar um Formulário no Access

A criação de formulários no Microsoft Access é bem simples. A criação de formulários exige tabelas prontas para atribuição de formulários a elas, com as tabelas prontas podemos criar os formulários de diversas formas, porém a forma mais simples e rápida mostrada a nós segue esse passo a passo:

1. Dentro do Access na página inicial onde podemos ver as tabelas, se encontra nas abas de cima onde escolhemos a gama de opções convenientes a nós, uma aba chamada de "Criar" ao lado da aba "Página Inicial";

2. Escolhendo a aba "Criar" vamos na opção localizada no meio das opções de criação "Assistente de Formulário";

3. Dentro dessa opção podemos escolher de qual tabela será o formulário e quais campos ele irá abordar;

4. Com a escolha das opções basta clicar no botão no canto inferior "Avançar".

## Modo de exibição e Criação Padrão de Formulário

A criação dos formulários seguem uma edição bem parecida com a criação de tabelas. Ao criar um formulário a alguns conceitos básicos para entendermos como funciona essa criação, um deles se relaciona indiretamente com a criação de tabelas, que é o modo de exibição, sendo eles a diferenciação da edição da tabela e da modificação de estrutura do formulário (conceituação):

- Modo design: O modo design é a onde editamos a parte estrutural do formulário. O modo permite a edição de propriedade de campos e modificação da estrutura do formulário, em resumo esse modo serve para criar as regras que os dados e propriedades do formulário vão seguir, ele autoriza se o formulário é movivel, se á barra de rolagem... entre outras funções que envolvem dados, eventos, layout entre outros;

- Modo de Exibição: O modo de exibição serve para editar, inserir e visualizar os dados. Dentro do modo de exibição que vamos interagir diretamente com a criação do formulário interagindo com com dados nas propriedades colocadas no modo design, isso possibilita a criação de registros de forma simples, é basicamente o utilitario para a criação de dados.

Além desse conceito de modo, a á possibilidade de criação padrão de formulários. Os formulários podem seguir um padrão criado pelo usuário, isso facilita caso ajá algum padrão dentro das necessidades do banco de dados em relação de entrada de dados, para criar um padrão é bem simples:

1. Dentro do Access na página inicial onde podemos ver as tabelas, se encontra nas abas de cima onde escolhemos a gama de opções convenientes a nós, uma aba chamada de "Criar" ao lado da aba "Página Inicial";

2. Escolhendo a aba "Criar" vamos na opção localizada no meio das opções de criação "Formulário em Branco";

3. Ao criar um formulário em branco podemos salvar esse formulário e dar um nome a ele clicando com o botão direito do mouse em cima do formulári;

4. Salvando o formulário podemos ir em "Arquivos" na aba de opção e ir na aba de "Opções" que se encontra na ultima posição da fileira de menu;

5. Dentro da aba escolhemos a terceira aba "Designers de Objetos", dentro do design de objetos rolamos um pouco para baixo e escolhemos a opção de "Modelo de formulário" que se encontra na gama "Modo de exibição de design de Formulário/Relatório";

6. Depois de escolher o formulário através de seu nomes, basta clicar no botão no canto inferior "Ok".
