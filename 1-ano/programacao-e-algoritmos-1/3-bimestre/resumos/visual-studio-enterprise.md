# Introdução ao Visual Studio Enterprise

## Visual Studio Enterprise

O Visual Studio Enterprise é uma IDE avançada voltada a grandes equipes, empresas e projetos complexos. Visual Studio Enterprise é um IDE que proporciona funções mais avançadas e profundas em testes, depuração, automação e arquitetura de software, diferente do Visual Studio Code a IDE aborda algo mais profundo e complexo. Nessa aula vimos apenas a interface e interagimos um pouco com a complexidade da IDE se aventurando pela interface.

## Interface

A Interface do Visual Studio Enterprise é extremamente carregada de opções e conceitos. A interface trás diversos ambientes de desenvolvimentos pré prontos, oque possibilita no foco e facilidade na criação, na visão geral da interface como um leigo, oque gostaria de pontuar seria:

- Junção de ferramentas: O Visual Studio Enterprise junta tudo em um só lugar dentro de uma tela, oque ajuda muito na locomoção entre ferramentas para analise dos dados;

- Github Copilot: Dentro da interface do Enterprise á uma inteligencia antificial entegrada ao Github que ajuda tanto nas duvidas em questão ao código ou a ferramenta e arquivos quanto na parte do Github que ajuda na criação de descrições das alterações do código, tira duvida sobre repositorios externos entre outras funções voltadas ao Github;

- IntelliTrace: O Intellitrace é um detector de erros extremamente inteligente que mostra até os erros de um código com milhoes de linhas, ele guarda execuções de código e permite a voltar para ver exatamente o erro, além disso ele gera logs e faz outras coisas muito úteis e interessantes;

- Azure: O Enterprise se conecta diretamente com computadores bons na nuvem, isso possibilita com o manuseio de dados gigantes que travam computadores comuns. Resumindo toda parte pesada roda na nuvem do Azure, sem derreter a máquina do usuário.

Em resumo, com o conhecimento adquirido através da exploração durante a aula, foram esses pontos que me chamaram mais atenção.
