# Interlúdio: Entendendo POO 

## Programação Orientada a Objetos

A Programação Orientada a Objeto (POO) é um modo de organização de código voltada a objeto. O POO é um modo de organização que utiliza "objeto" para imitar coisas da vida real, é basicamente a utilização de objetos para melhor compreensão do código e facilidade na reutilização de um código, ao invés de seguir a lógica de passo a passo o código vai seguir uma orientação a moldes com dados e ações para montar programas. O POO se utiliza de Classes, Objetos, Atributos e Métodos para construir um código.

- Classe: O molde que define como o objeto vai ser;
- Objeto: A cópia real criada a partir da classe;
- Atributos: As características ou dados do objeto (ex: nome, cor, modelo);
- Métodos: As ações que o objeto pode fazer (ex: andar, falar, organizar).

## Pilares do POO

Os pilares do POO são os principais conceitos que definem um código estilo POO. O POO se aplica a diversas linguagens, por tanto a pilares a ser seguidos para um código se enquadrar no conceito de POO:

- Encapsulamento: Esconder dados difíceis e proteger o código;
- Herança: Passar partes de uma classe para outra, evitando a repetiçã de código;
- Polimorfismo: Permitir ações iguais com formas diferentes de agir;
- Abstração: Focar nos pontos principais do momento.
